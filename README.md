# Демо панели управления Axe Point

Статический макет панели для предварительного показа Михаилу. Включает пример разделов для редактирования цен и фотографий. Данные демонстрационные: сохранение, загрузка фото и связь с сайтом не подключены.

## Публикация через GitHub Pages

1. Загрузить папку `admin-demo` в корень репозитория Axe Point.
2. В настройках репозитория открыть **Settings → Pages** и включить GitHub Pages для нужной ветки.
3. После публикации открыть `https://<владелец>.github.io/<репозиторий>/admin-demo/`.

Страница и изображения уже находятся внутри этой папки, дополнительных файлов сайта для демо не требуется.
